# Сапёр (pygame-ce)

8×8 алаңдағы Сапёр ойыны, 10 мина. Ойын pygame-ce кітапханасымен жазылған және өз терезесінде ашылады.

## Орнату және іске қосу

1. Python орнатылған болуы керек.
2. Кітапхананы бір рет орнатыңыз: `python -m pip install pygame-ce`
3. Барлық файлдар бір папкада тұруы керек. Папканы VS Code-та ашып, `main.py` файлын іске қосыңыз.

## Ойын экрандары

1. **Бастапқы экран:** ойынның аты және пернелер. Бастау үшін Enter.
2. **Ойын экраны:** алаң, уақыт, ұпай.
3. **Соңғы экран:** жеңдіңіз бе, жеңілдіңіз бе, қорытынды ұпай, қайта бастау (R).

## Пернелер

| Перне | Не істейді |
|---|---|
| Enter | бастапқы экраннан ойынды бастайды |
| Стрелкалар | таңдалған ұяшықты жылжытады |
| Space | таңдалған ұяшықты ашады |
| R | соңғы экраннан ойынды қайта бастайды |

## Ұпай

Әр қауіпсіз ұяшық үшін 10 ұпай, жеңсеңіз қосымша 200 ұпай.

## Кластардың сұлбасы

```
GameObject            (ата-ана: қатар, баған, rect, set_place, draw, update)
├── Cell              (is_open, reveal, on_game_over; draw қайта анықталған)
│   ├── SafeCell      (count; draw және reveal қайта анықталған)
│   └── MineCell      (exploded; draw, reveal, on_game_over қайта анықталған)
└── Cursor            (стрелкалармен жылжиды; draw қайта анықталған)

Board   миналарды қояды, ұяшықтарды жасайды
Timer   уақытты санайды
Game    ортақ класс: self.cells, self.objects (SafeCell, MineCell және Cursor бір тізімде),
        күйі (start, play, end), ұпай, ашылған ұяшық саны
```

## Кім қай класты жазды
