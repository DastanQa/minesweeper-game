# Сапёр (pygame-ce)

8×8 алаңдағы Сапёр ойыны, 10 мина. Ойын **pygame-ce** кітапханасымен жазылған және өз терезесінде ашылады.
Мақсат: миналарды баспай, барлық қауіпсіз ұяшықты ашу.

## pygame-ce қалай орнатылады және ойын қалай іске қосылады

1. Python орнатылған болуы керек.
2. Кітапхананы бір рет орнатыңыз: `python -m pip install pygame-ce`
3. Репозиторийді архив етіп жүктеп алыңыз (GitHub → Code → Download ZIP) және архивті ашыңыз.
4. Папканы VS Code-та ашып, `main.py` файлын іске қосыңыз (немесе папкада `python main.py`).
5. Windows-та `start.bat` файлын екі рет басуға да болады. Оған ярлык жасап, жұмыс үстеліне қоюға болады:
   файлды тінтуірдің оң жағымен басыңыз → «Жіберу» → «Жұмыс үстелі (ярлык жасау)».

`main.py`, барлық `.py` файлдар және `assets/` папкасы бір папкада тұруы керек.

## Ойын экрандары

1. **Бастапқы экран:** ойынның аты, пернелер. Бастау үшін Enter.
2. **Ойын экраны:** алаң, уақыт, ұпай, қалған мина саны.
3. **Соңғы экран:** жеңдіңіз бе, жеңілдіңіз бе, қорытынды ұпай, қайта бастау (R).

## Пернелер

| Перне | Не істейді |
|---|---|
| Enter | бастапқы экраннан ойынды бастайды |
| Жебелер | таңдалған ұяшықты жылжытады |
| Space | таңдалған ұяшықты ашады |
| F | таңдалған ұяшыққа жалау қояды немесе алады |
| R | ойынды қайта бастайды |
| Esc | ойын кезінде мәзірге оралады; мәзірде және соңғы экранда ойыннан шығады |

## Ереже және ұпай

- Ұяшықтағы сан: оның айналасындағы 8 ұяшықта қанша мина бар екенін көрсетеді.
- Айналасында мина жоқ ұяшықты ашсаңыз, оның айналасы автоматты түрде ашылады.
- Бірінші ашылған ұяшықта мина болмайды. Жалауды бірінші ұяшықты ашқаннан кейін қоюға болады.
- Миналы ұяшықты ашсаңыз, жеңілесіз: жарылыс болады, барлық мина көрінеді.
- Барлық қауіпсіз ұяшықты ашсаңыз, жеңесіз.
- Әр қауіпсіз ұяшық үшін 10 ұпай, жеңсеңіз қосымша 200 ұпай.

## Кластардың сұлбасы

```
pygame.sprite.Sprite
├── GameObject            (ата-ана: row, col, image, rect; set_place, update)
│   ├── Cell              (is_open, flagged; reveal, toggle_flag, on_game_over)
│   │   ├── SafeCell      (count; reveal қайта анықталған, is_empty)
│   │   └── MineCell      (exploded, frames; reveal, on_game_over, update қайта анықталған)
│   └── Cursor            (frames; move, find_cell; update қайта анықталған)
└── Particle              (dx, dy, life; move, age; update қайта анықталған)

Game  ортақ класс. Нені сақтайды:
      self.cells    - Group: тек ұяшықтар (SafeCell және MineCell), курсормен соқтығысуды тексеру үшін
      self.objects  - Group: ұяшықтар мен курсор (түрлі класс бір топта, бір update/draw)
      self.effects  - Group: бөлшектер (Particle)
      self.cell_list, self.mine_spots, self.waiting, күйі (start, play, over), ұпай, ашылған ұяшық саны
```

Полиморфизм: `Game` ұяшыққа түрін тексермей `cell.reveal(self)` және `obj.on_game_over()` деп шақырады.
`SafeCell` мен `MineCell` әрқайсысы өз нұсқасын орындайды. `self.objects.update()` ұяшықтар мен курсорға
`update()` шақырады: `MineCell` пен `Cursor` өздерін анимациялайды.

Соқтығысу: `Cursor.find_cell` курсор тұрған ұяшықты `pygame.sprite.spritecollide` арқылы табады.

## Кім қай класты жазды

| Қатысушы | Файлдар |
|---|---|
| Жамбыл Дастан | game_object.py (`GameObject`), cursor.py (`Cursor`) |
| Ардхан Мадияр | cell.py (`Cell`), particle.py (`Particle`) |
| Бекмурат Нургиса | safe_cell.py (`SafeCell`), game.py (`Game`) |
| Қалмұрза Оразкелді | mine_cell.py (`MineCell`), settings.py, main.py |

## Суреттер, дыбыстар және қаріп қайдан алынды

- Барлық сурет (`assets/*.png`) және дыбыс (`assets/*.wav`) Python скриптімен (Pillow, numpy, wave) жасалған,
  дайын жинақтан алынбаған. Лицензия шектеуі жоқ.
- Қаріп: **DejaVu Sans** (`assets/font.ttf`, `assets/font_bold.ttf`), еркін лицензия (Bitstream Vera / DejaVu license).
  Қаріп `assets/` ішінде тұр, сондықтан ойын кез келген компьютерде іске қосылады.

## Анимация және әсерлер

- Анимация: ашылған мина төрт сурет (`mine_0..3.png`) кезекпен ауысады; курсор жақтауы екі кадрмен жыпылықтайды.
- Әсерлер: ұяшық ашылғанда және жарылғанда ұсақ бөлшектер шашырайды (`Particle`), жарылғанда экран шайқалады.
- Дыбыс: ұяшық ашу, жалау, жарылыс, жеңіс, жеңіліс.
