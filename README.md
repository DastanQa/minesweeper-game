# Сапёр (pygame-ce)

Сапёр ойыны 8×8 алаңда, 10 мина. Ойын pygame-ce кітапханасымен жазылған және өз терезесінде ашылады.

## Іске қосу

1. Python орнатылған болуы керек. Кітапхананы бір рет орнатыңыз: `pip install pygame-ce`
2. Барлық файлдар бір папкада тұруы керек.
3. Папканы VS Code-та ашып, `main.py` файлын іске қосыңыз.

## Пернелер

| Перне | Не істейді |
|---|---|
| Стрелкалар | таңдалған ұяшықты жылжытады |
| Бос орын (Space) | таңдалған ұяшықты ашады |
| R | ойын біткен соң қайта бастайды |

## Ережелер

- Ашылған қауіпсіз ұяшықта айналасындағы миналар саны көрсетіледі.
- Миналы ұяшықты ашсаңыз, ойын жеңіліспен аяқталады, барлық мина көрінеді.
- Барлық 54 қауіпсіз ұяшықты ашсаңыз, жеңесіз.
- Ойын барысында уақыт саналады, ойын біткенде тоқтайды.

## Файлдар және кластар

| Файл | Класс | Не істейді |
|---|---|---|
| settings.py | | алаң өлшемі, мина саны, шрифт жолы |
| cell.py | `Cell` | ата-ана класы: ұяшықтың ортақ атрибуттары мен әдістері |
| safe_cell.py | `SafeCell(Cell)` | қауіпсіз ұяшық, `draw` және `reveal` әдістерін қайта анықтайды |
| mine_cell.py | `MineCell(Cell)` | миналы ұяшық, `draw`, `reveal`, `on_game_over` әдістерін қайта анықтайды |
| board.py | `Board` | миналарды кездейсоқ қояды, ұяшықтарды жасайды |
| cursor.py | `Cursor` | таңдалған ұяшықты жылжытады |
| timer.py | `Timer` | ойын уақытын санайды |
| game.py | `Game` | барлық объектіні біріктіреді, жеңіс пен жеңілісті тексереді |
| main.py | | ойын циклі, іске қосу нүктесі |
